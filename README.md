# AI Ready Colombo

**AI Ready Colombo** is a practical AI literacy learning experience for students, recent graduates and early-career professionals. It focuses on using generative AI effectively while keeping verification, privacy and human judgment in the loop.

**Tagline:** Practical AI skills for a changing world.

Live site: https://ravindunawanjana.github.io/ai-ready-colombo/

## What this repository contains

This repository contains the complete static website for AI Ready Colombo, including the five learning modules, assessments, learner resources, privacy information and the downloadable toolkit.

The site is built with HTML, CSS and JavaScript and is designed for GitHub Pages. It also includes lightweight animation and interaction libraries used across the learning experience.

## Learning journey

The programme is organised into five modules:

1. **Understanding AI** — what generative AI is, where it helps and where it can fail.
2. **Working With AI** — practical prompting using the CTCO framework: Context, Task, Constraints and Output.
3. **AI for Real Work** — using AI to support everyday study and work tasks without handing over judgment.
4. **Responsible AI** — verification, bias, privacy and safer use of AI tools.
5. **Build Your AI Workflow** — turning the course ideas into a repeatable personal workflow.

The learner journey also includes a baseline form, final assessment, completion page and feedback form.

## Privacy and AI disclosure

`privacy.html` explains practical privacy concepts for learners. `privacy-notice.html` explains how the website, assessments and certificate workflow handle information. `ai-disclosure.html` explains how generative AI supported parts of the project’s development and where human review remains responsible.
